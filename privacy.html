PRIVACY

The short version: this site doesn't track you.

01/ WHAT THIS SITE DOES

This is a static personal portfolio. There are no cookies, no analytics, no forms that collect data, and nothing is sent to a server on your behalf — everything you see (fonts, images, code) is bundled directly into the page you loaded.

02/ THIRD-PARTY REQUESTS

None. Fonts used to be loaded from Google Fonts on every visit — that request would have sent your IP address to Google's servers. Both fonts (Elektron Pixel Font and JetBrains Mono) are now self-hosted, embedded directly in the page, so no such request happens anymore.

03/ LINKS TO EXTERNAL SITES

This site links out to things like GitHub, Bandcamp, Instagram, YouTube, and similar platforms. Once you click through, you're on their site under their own privacy policy — this page only covers antonelse.github.io itself.

04/ HOSTING

The site is hosted on GitHub Pages. GitHub may log basic server access data (like IP addresses) as part of running the hosting infrastructure — that's outside this site's control; see GitHub's own privacy statement for details.

This isn't legal advice — just a plain description of how the site is built. If anything changes (analytics, forms, a contact widget, etc.), this page will be updated to reflect it.
